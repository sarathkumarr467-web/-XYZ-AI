# XYZ AI School Assistant

An AI-powered school management system designed to help schools manage students, teachers, attendance, and academic reports through a simple web dashboard.

## 🚀 Features

- Principal Dashboard
- Student Management
- Teacher Management
- Attendance Management
- Automatic Attendance Percentage Calculation
- Academic Reports
- Live Database Integration
- FastAPI Backend
- Interactive Web Interface
- REST API Support
